手动安装教程

视频悬浮窗 VideoMask · v1.6.29 · 全程不用 AI，大约 5 分钟

这份教程是给不想让 AI 动自己电脑的人写的。全程只有 5 步， 每一步都写了「怎么确认这一步做对了」——卡住的时候回头看这一步的验证方法就行。

看不懂就先看这句：这个脚本不是程序，双击不会打开任何东西。 它只是一个文件夹，放进 BetterGI 的指定目录，然后在 BetterGI 里设置两处开关就完事了。

1准备两样东西

BetterGI 版本 0.50.0 或更新。不知道版本？打开 BetterGI，标题栏或 「设置」页面底部会写版本号。
没有的话先去 bettergi.com 装一个，装完能正常启动再来。
VideoMask 安装包 VideoMask_v1.6.29.zip（约 620 KB）

2解压

  1. 右键 zip → 全部解压缩（Win11 是「全部提取」）→ 随便选个位置，比如桌面。
  2. 解压出来是一个 VideoMask 文件夹，打开它，里面应该直接能看到这些东西：
VideoMask\ ├─ main.js ← 脚本主体，最重要 ├─ manifest.json ├─ settings.json ├─ README.md ├─ 使用教程.html └─ assets\
别双击任何文件。main.js 不是能运行的软件，双击它只会用记事本打开一堆代码。 这个文件夹是要整个搬走的，不需要在这里做任何操作。

3把文件夹放进脚本目录

这一步最容易错，所以不要自己去找 BetterGI 装在哪个盘，让 BetterGI 自己告诉你：

  1. 打开 BetterGI，顶部点 全自动，再点下面的 JS 脚本 选项卡。
  2. 页面里有个按钮叫 打开脚本目录，点它。

示意图。按钮名字就是「打开脚本目录」，点它不要在别处找。

  1. 会弹出一个资源管理器窗口，地址栏是类似 ...\BetterGI\User\JsScript 的路径——这就是要放的位置。
  2. 把你解压出来的 VideoMask 文件夹整个拖进去（不是拖 main.js，是拖文件夹）。

放完之后，目录应该是这个层级：

...\BetterGI\User\JsScript\ └─ VideoMask\ ├─ main.js ├─ manifest.json ├─ settings.json └─ assets\
最常见的错误：多套了一层。如果你看到的是 JsScript\VideoMask\VideoMask\main.js，就是拖错了——把里面那层 VideoMask 剪切出来，让 main.js 正好躺在 JsScript\VideoMask\ 下面。

4回 BetterGI 确认脚本认出来了

  1. 回到刚才的 JS 脚本 页面，点 刷新。
  2. 列表里应该出现一项叫 视频悬浮窗。
这一步的验证方法：能看到「视频悬浮窗」四个字就算过。 看不到 → 回第 3 步检查是不是多套了一层文件夹，或者文件没放进去。

5建配置组，把脚本加进调度器

不建配置组，脚本也能单独跑，但没法放进「全自动」一条龙里， 以后每次都得手动点。所以顺手建一个，一劳永逸。

  1. 顶部 全自动 → 点 调度器 选项卡。
  2. 点 新增配置组，名字随便起，比如 看攻略，确定。
  3. 点一下刚建好的 看攻略 标签，让它选中（标签会高亮）。
  4. 点 添加 → 在弹出菜单里选 JS 脚本 → 再选 视频悬浮窗。

验证方法：「看攻略」这个标签下面出现了「视频悬浮窗」这一行，就算过。

6打开 JS HTTP 权限（最容易漏的一步）

这个脚本要联网取 B 站的视频地址、合集列表、弹幕，BGI 默认把这类请求全拦掉。

  1. 还在 调度器 页面，找 通用设置（有的版本是页面右上角的一个齿轮图标）。
  2. 里面有一项 启用 JS HTTP 权限，勾上。
  3. 关掉 BetterGI 再重新打开。
调度器 → 通用设置
启用 JS HTTP 权限  ← 勾上这个
启用 JS 通知

示意图。勾完必须重启 BetterGI，不然这次不会生效。

为什么一定要重启？这个开关是在 BetterGI 启动时读取的。勾完不重启， 你会看到「视频能播，但侧栏是空的 / 一直转圈」——很多人以为装坏了，其实就是没重启。
不用填任何网址。允许访问哪些网站，是脚本自己的 manifest.json 里写好的（都是 bilibili 的域名），你只需要打开上面这个总开关。

7运行

  1. 先打开游戏（原神窗口在前台）。
  2. 回 BetterGI，全自动 → 调度器，选中「看攻略」配置组，右键「视频悬浮窗」→ 运行； 或者直接点页面上的 运行 按钮。

游戏画面上会出现一个半透明的小窗口，写着「还没选视频」——这是正常的，说明脚本起来了。

8第一次用：选一集

  1. 按 Insert，把鼠标从游戏要回来（浮窗边缘会变亮）。
  2. 点浮窗里的 打开节目单，或者按一下 Alt 再点右上角的 ☰。
  3. 按 地图 → 分类 → 版本 → 分P 的顺序选一集，点了就开始播。
  4. 再按一次 Insert，鼠标还给游戏，可以正常操作了。
选过就记住了。下次启动直接接着上次那一集播，这张引导页不会再出现。 默认播放/暂停是 ~（Esc 下面那颗），因为笔记本的 F9 经常被亮度键占用。

9装完自检（5 条，30 秒）

检查什么应该是
目录层级JsScript\VideoMask\main.js 直接存在
JS 脚本列表有一项「视频悬浮窗」
调度器配置组配置组里能看到「视频悬浮窗」
通用设置「启用 JS HTTP 权限」是勾着的
运行后游戏上出现「还没选视频」的半透明窗口

五条全对就装好了。有一条不对，对照下面这一节。

10装不上时对照这里

① 脚本列表里找不到「视频悬浮窗」

  • 先点 刷新。
  • 还不行 → 关掉 BetterGI 重开（脚本列表是启动时扫的）。
  • 还没有 → 九成是多套了一层：要 JsScript\VideoMask\main.js， 不是 JsScript\VideoMask\VideoMask\main.js。
  • 检查一下 main.js 文件大小，正常应该是 150 KB 左右。 如果只有几 KB，说明下载的是网页不是脚本。

② 窗口出来了，但侧栏空的 / 一直转圈

  • 先确认第 6 步做完并且重启过 BetterGI。这是最常见的原因。
  • 还是空 → 视频能播吗？能播说明只是网络慢，等几秒点画面上的「重试」。
  • 完全不能播 → 可能是 B 站风控。在浮窗的 Ctrl 面板里填自己账号的 SESSDATA。

③ 双击 main.js 没反应 / 打开一堆代码

  • 这是正常的。main.js 不是程序，不用双击，只负责躺在那里被 BetterGI 读取。

④ 开了浮窗，BetterGI 的自动拾取 / 自动剧情不动了

  • 脚本会自动把它们挂回来（日志里会有「已把 BGI 的实时触发挂回来」）。
  • 日志里没有这一行 → BetterGI 版本太老，升级 BGI。
  • 有这一行但还是不动 → 大概率是浮窗压住了识别区。 把浮窗挪到画面边角（拾取提示在左侧中部、对话选项在底部中间）， 或者在 BetterGI 启动页把截图方式换成 WindowsGraphicsCapture。
  • 另外确认 BetterGI 设置里的 后台运行 是开着的。

⑤ 怎么确认脚本真的跑起来了

  • 看日志：...\BetterGI\log\ 里今天那个 better-genshin-impact2026xxxx.log。
  • 搜 VideoMask v1.6.29 启动，搜到就是起来了。

11以后出新版本怎么更新不用重装

  1. 关掉 BetterGI。
  2. 下载新的 zip，解压，把里面的文件覆盖到 JsScript\VideoMask\。
  3. 重新打开 BetterGI，跑一次就行。
覆盖不会丢设置。你在浮窗里调过的位置、倍速、看到第几分钟， 以及面板里填的 SESSDATA，都存在别的地方，不在这个文件夹里。
唯一可能失效的是 JS HTTP 权限。如果新版本的 manifest.json 增加了新的域名，BetterGI 会要求重新授权一次—— 表现是侧栏又空了。这时回到第 6 步，把那个总开关关掉再打开、重启 BGI 即可。

12不想用了怎么删干净

  1. 关掉 BetterGI。
  2. 删掉整个 JsScript\VideoMask\ 文件夹。
  3. 打开 BetterGI → 调度器 → 右键「视频悬浮窗」→ 移除；不需要这个配置组就一起删掉。
  4. 重新打开 BetterGI，脚本列表里就没了。

它没有安装到系统里，不写注册表，不开机启动，删掉文件夹就等于没装过。

还装不上？把这三样发给作者，比描述一百句都管用：

  • BetterGI 的版本号
  • JsScript\VideoMask\ 这一层的截图（能看到 main.js 就在里面）
  • ...\BetterGI\log\ 里今天那个日志文件
