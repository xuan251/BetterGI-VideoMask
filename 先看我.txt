视频悬浮窗 VideoMask  v1.6.28
================================

【这是什么】
BetterGI 的一个脚本。装上后，游戏画面上浮一个视频窗口，直接播 B 站原神攻略视频；
播到"该你打怪"的地方会自动暂停，让你自己打完再继续。

【懒人装法（推荐）】
把同目录下的「给AI的安装指令.md」整份发给你自己的 AI 助手，让它照着做。
它会自己找 BetterGI 目录、复制文件、改好配置、逐项校验，只剩最后一步需要你点。

【手动三步装上】
1. 把这个 VideoMask 文件夹整个复制到：
   BetterGI\User\JsScript\VideoMask\
   （放好后 main.js 应该正好在这个路径下，别多套一层文件夹）

2. 打开 BetterGI 设置，勾上「JS HTTP 权限」

3. 刷新 BetterGI，运行「视频悬浮窗」

【第一次用】
· 窗口里会有一张半透明引导页，写着「还没选视频」
· 按 Insert 把鼠标要回来
· 点黄色按钮「打开节目单」（点窗口任意位置也行）
· 按 地区 → 分类 → 系列 → 分P 选一集，开始播
· 再按一次 Insert，鼠标还给游戏

【系列栏会自己收回】
它就是"临时挑片"用的，不是常驻面板：
· 选完视频 → 自动关
· 松开 Alt → 自动关
· 鼠标挪出浮窗、或者点回游戏 → 自动关
手动关也行：按 Esc，或者再点一下工具栏的 ⧉

【之后再打开】
不用再选了。脚本记得你看到哪一集、第几秒，直接接回来自动播。

【自己加视频】
把 mp4 放进  VideoMask\assets\videos\
然后打开侧栏 → 最上面多一个「本地视频」卡片 → 点进去就是一个文件列表，点哪个播哪个。
刚放进去没看到？点侧栏右上角的 ↻ 重新扫一遍，不用重开脚本。
（只认 mp4 / m4v / webm / mov；mkv、avi 播不了，不会列出来）

【热键】
Insert  切「鼠标穿透 / 可交互」  ← 最常用
~       播放 / 暂停（Esc 下面那颗波浪号键）
按住 Alt 临时可交互（拖进度条方便）
End     开关 B 站登录窗

【打怪点自动暂停】
已默认开启，播视频时自动生效。
· 打怪点：他说"把怪清一下"→ 立刻停
· 看完再停：限时挑战/打 boss → 整段看完才停
嫌烦：
· 想少停一点 → 设置里把「暂停点最小间隔」从 20 改成 30~45
· 完全不要   → ⚙ →「打怪点」那行点成「关」

【卡住了怎么办】
取地址超过 12 秒、或 25 秒还没起播，画面会直接告诉你原因，并给一个「重试」按钮。
点重试还不行，就照提示里写的做（比如去勾「JS HTTP 权限」）。

【重要提醒】
浮窗处于「可交互」状态时会抢游戏前台焦点，可能导致 BetterGI 自带的
自动剧情失效。调完设置记得按 Insert 切回穿透；
或者到 BetterGI 设置里打开「后台运行」（最彻底）。

【详细教程】
双击打开同目录下的  使用教程.html  （任何浏览器都能开，带截图）
