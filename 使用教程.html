视频悬浮窗 VideoMask

把原神攻略视频浮在游戏窗口上，边玩边看 · 版本 1.6.28

这是一个 BetterGI 的 JS 脚本。装好之后，游戏画面上会浮一个可以拖动、可以收起的视频窗口， 里面直接播 B 站的攻略视频；播到"该你打怪"的地方会自动暂停，让你自己打完再继续。

1装之前要有的东西

必需 BetterGI（版本 0.50.0 或更新）
BetterGI 是一个原神自动化工具，本脚本是它的插件，不能单独运行。
系统 Windows 10 / 11，需要 BetterGI 自带的 WebView2（一般装好 BGI 就有了）
可选 B 站账号的 SESSDATA —— 只有想看字幕和方向箭头提示才需要，不给也能正常播

2安装（四步）

懒得动手？让你的 AI 装。把同目录的 给AI的安装指令.md 整份发给你常用的 AI 助手， 它会自己找 BetterGI 目录、复制文件、改配置、逐项校验，最后只剩第 2 步的勾选要你点。
  1. 把 VideoMask 文件夹整个放进 BetterGI 的脚本目录
    目标路径：BetterGI\User\JsScript\VideoMask\
    放完之后，main.js 应该正好在这个路径下： ...\BetterGI\User\JsScript\VideoMask\main.js，不要多套一层文件夹。
  2. 在 BetterGI 设置里勾上「JS HTTP 权限」
    侧栏、弹幕、字幕、合集列表都要靠它联网，不开就只有一个空窗口。
  3. 刷新 BetterGI
    在脚本列表里点刷新，应该能看到一个叫「视频悬浮窗」的脚本。
    想让「全自动 → 调度器」里也能直接跑它：调度器 → 选中配置组 → 右键「添加」→ 选 JS 脚本 → 视频悬浮窗。 用上面的 AI 指令安装的话，这一步会连权限一起自动配好。
  4. 运行它
    游戏画面上会出现一个视频窗口。第一次是一张半透明的引导页（写着「还没选视频」）， 按 Insert 后点「打开节目单」选一集即可。
为什么第一次不直接播？ 攻略是按地区分的（枫丹 / 须弥 / 璃月…）， 随便播一个大概率不是你要看的那集。所以第一次让你选一次， 选过之后就记住了——以后启动直接接着上次那一集播，引导页不会再出现。

3第一次用：选一集来看

运行之后，视频窗口里会出现一张引导页（半透明，游戏画面能看到），上面写着 「还没选视频」和一个黄色的「打开节目单」按钮。

  1. 按 Insert 把鼠标"要回来"（这时候鼠标可以点浮窗，游戏暂时不动）
  2. 点黄色按钮「打开节目单」（点窗口任意位置也行）
  3. 按「地区 → 分类 → 系列 → 分P」一层层点进去，点到某一集
  4. 视频开始播之后，再按一次 Insert，鼠标就还给游戏了，你可以正常操作

节目单最上面还会有一个「本地视频」卡片—— 那是你在 assets\videos\ 里自己放的 mp4，点进去直接播。

第二次开就不用选了。脚本会记住你看到哪一集、第几秒， 下次运行直接把那一集接回来自动播，连引导页都不出现。

4核心功能：播到打怪点自动暂停

这是这个脚本最要紧的部分。它已经默认开着，播视频时自动生效，不用你设置。

它怎么判断"该你打怪了"

不是靠"看到宝箱就停"这种傻规则——那种做法在路上随便遇到个宝箱就会误停。 这里是把 UP 主（影月月）全集 566 集、共 4950 分钟的视频全部转成文字， 统计出"他说某类话之后，有多大概率叫你自己打"，再按概率排出每一集该停在第几秒。

统计结果大致是这样：

他说的话之后要打怪的概率所以
「镇守宝箱」82%基本都要打，停
「这个神瞳」16%多半不用停
「这里有个宝箱」14%永远不单独停——路上遇到宝箱不会再打断你了

一共排出了 1526 个暂停点，分两种：

  • 打怪点（1356 个）：他说"把怪清一下"，视频立刻停住，提示"打完再按播放"。
    时间轴上是红点。
  • 看完再停（170 个）：限时挑战、打 boss、讲操作这种，整段演示看完才停， 提示"这段看完了 轮到你上"。
    因为这类内容停早了等于没教你怎么打。时间轴上是青点。

觉得烦？随时关掉，或者调稀一点

点控制栏的 ⚙ 打开设置面板 → 找到「打怪点」那一行 → 点一下「开」变成「关」。

关掉会存进设置，重开脚本也还是关着，不会自己又弹回来。 想再开就再点一下。也可以在 BetterGI 的脚本设置里取消勾选「打怪点到点自动暂停」。

只想少停一点、不想全关：把设置里的 「暂停点最小间隔」从 20 改成 30~45（间隔小于它的两个点会合并成一个）。

5鼠标怎么还给游戏

浮窗有两种状态，靠 Insert 切换：

状态效果
鼠标穿透（默认）鼠标可以点游戏、打怪，浮窗只是"贴"在画面上，不挡操作
可交互鼠标可以点浮窗：拖进度条、点按钮、开侧栏。此时游戏暂时点不到
重要：看攻略时别一直开着"可交互"。浮窗可交互时会抢游戏的前台焦点， 可能导致 BetterGI 自带的「过剧情 / 自动剧情」失效。 调完设置就按 Insert 切回穿透。

如果确实需要一边挂着浮窗一边自动过剧情，请到 BetterGI 设置里打开「后台运行」， 这样游戏不在前台也能自动操作。

6常用热键

按键作用
Insert切换「鼠标穿透 / 可交互」（最常用）
~播放 / 暂停（Esc 下面那颗波浪号键；笔记本的 F9 常被亮度键占用，所以不用 F9 了）
Alt（按住）临时变成可交互，松开就退回穿透——拖进度条很方便
End开关 B 站登录窗（登录窗会全屏盖住画面，只能靠它关）

其它热键（快进、快退、调速、透明度、上一集…）都能在 ⚙ 面板里改， 默认多数是空的，需要自己去绑。

别去绑 F12 / F5。浮窗内核是浏览器，F12 会弹出开发者工具、F5 会刷新页面把进度清零。 脚本默认已经帮你避开了这些键（设置里叫「热键避开浮窗浏览器的快捷键」，保持开启）。

7可选：字幕和方向提示

想要视频下方的字幕、以及"往西南走"这种方向箭头提示，需要填 B 站登录凭证。 不要这两个功能的话，完全跳过这一步，其它一切正常。

  1. 浏览器登录 B 站
  2. 按 F12 → 应用 / 存储 → Cookie → bilibili.com
  3. 找到 SESSDATA，复制它的值（很长一串）
  4. 粘到 BetterGI 里这个脚本的设置项「B站 SESSDATA」
SESSDATA 等于你的登录凭证，别发给任何人。它只存在你自己电脑上 BetterGI 的配置里， 脚本不会上传。想让它失效：B 站 → 设置 → 安全 → 退出所有设备。

8常见问题

窗口里只有一张引导页 / 不播视频

  • 说明还没选过片。按 Insert，点「打开节目单」，选一集就开始播。
  • 如果侧栏是空的：检查 BetterGI 有没有开「JS HTTP 权限」，然后重开脚本。
  • 选过一次之后就不会再出现引导页了，下次直接接着看。

视频一直转圈 / 加载失败

  • 先等 12 秒。取地址超过 12 秒、或者地址拿到了但 25 秒还没起播， 画面会直接弹出原因和一个「重试」按钮，不用干等。
  • 点「重试」还不行，看提示里的文字：写「JS HTTP 权限」就去 BetterGI 设置里勾上。
  • B 站有时限制匿名播放，试试在设置里填上 SESSDATA 再重开。
  • 清晰度只支持 360P / 720P（直链自播的限制），设置里「在线清晰度」保持 720P 最稳。

开了浮窗，BetterGI 的自动剧情就不能用了

  • 原因：浮窗进入「可交互」状态时会抢游戏前台焦点，游戏一失焦， BGI 的自动剧情（在没开后台运行的情况下）就点不到游戏了。
  • v1.6.27 已从源头关掉最主要的两个触发： 「启动后可拖动多少秒」默认改成 0（以前默认 25 秒，等于每次启动都抢 25 秒焦点）； 「进度条热区 / 鼠标悬停」默认也是关的。
  • 如果还是不行：按 Insert 切回鼠标穿透； 或到 BetterGI 设置里打开「后台运行」（这是最彻底的解法）。

打怪点停得太频繁 / 停的位置不对

  • 先调「暂停点最小间隔」（默认 20 秒）。这是同一集里两个点靠太近就合并成一个的阈值—— 他有时候会先后说两句"把怪清一下"，中间只隔十几秒，原样播会停一下、点继续、十几秒后又停。
    改成 30~45 会更少打断（总点数从 1526 降到 1375 / 1292）；填 0 则不合并，全保留。
  • 还是太频繁：⚙ → 「打怪点」直接关掉。
  • 位置不对：可以手动调整——控制栏的「＋怪」能在当前时刻补一个点， 靠近已有的点会移动它，Shift + 点击能删掉。

系列栏（侧栏）关不掉 / 挡视野

  • v1.6.28 起它会自己收回：选完视频、松开 Alt、 鼠标挪出浮窗、或者点回游戏，系列栏都自动关掉，不用再去点一次 ⧉。 手动关也可以：按 Esc，或再点一下 ⧉。
  • 它只在"你正在挑片"的时候存在，不是常驻面板——想看当前在播哪一集， 画面下方那行字幕/方向提示和 Ctrl 面板里的进度就够了。
  • 设置里勾着「显示合集侧栏」的话：每次按 Alt 它还是会自己摆出来， 松开再收回，不用每次去点 ⧉。

能自己加视频吗

  • 能，而且不用改设置。把 mp4 放进脚本目录下的 assets\videos\， 打开侧栏，最上面会多出一个「本地视频」卡片，点进去就是一个文件列表，点哪个播哪个。
  • 刚放进去没看到？点侧栏右上角的 ↻ 重新扫一遍，不用重开脚本。
  • 只列 mp4 / m4v / webm / mov。mkv、avi 这类多数播不了，不会列出来。
  • 也可以直接填 B 站 BV 号 / 链接（设置里「在线视频 BV号」），填了就优先播在线的，不用下载。

9不想要了怎么删干净

  1. BetterGI 脚本列表里停掉「视频悬浮窗」
  2. 删掉 BetterGI\User\JsScript\VideoMask\ 整个文件夹
  3. BetterGI 的配置里删掉这个脚本对应的配置组（可选，留着也不影响）
